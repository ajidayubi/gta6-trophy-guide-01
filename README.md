Leonida Platinum Roadbook is a comprehensive offline web app tracking all 55 Grand Theft Auto VI trophies. It features saved progress in local storage, interactive category and search filters, a spoiler setting hiding story spoilers by default, an actionable platinum roadmap, detailed guides for every trophy with cited sources, and JSON progress export and import.

## Run it

```bash
node serve.ts
```
